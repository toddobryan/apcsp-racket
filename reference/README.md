# Reference material

Not part of any package — these are pedagogical sources, not shipped docs.

- `SchreibeDeinProgramm.pdf` — *Schreibe Dein Programm!*, Michael Sperber and
  Herbert Klaeren. Licensed CC BY-SA 4.0.
- `WriteYourProgramPart1.pdf`, `WriteYourProgramPart2.pdf` — machine translation
  of the above.

This is the source for the signature system's `(: name (Arg -> Result))` notation.
Moved here from the archived `toddobryan/apcsp` repo, which previously held them
under `apcsp-doc/`. They are deliberately *not* in `apcsp-doc/`: that name is
reserved for the Scribble documentation package students would install.
